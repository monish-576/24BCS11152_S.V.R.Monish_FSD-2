# ✅ Todo List

A simple Todo List application built with React that helps users manage daily tasks efficiently.

## Features

- ➕ Add new tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 📋 Display all tasks
- 📱 Responsive design

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Installation

```bash
cd todo-list
npm install
npm run dev
