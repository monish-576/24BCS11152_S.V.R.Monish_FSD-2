# 🚀 React Projects Collection

This repository contains a collection of beginner-friendly React projects developed using **React**, **Vite**, **JavaScript**, and **CSS**. Each project demonstrates fundamental React concepts such as components, state management, event handling, and responsive UI development.

## 📂 Projects

### ⏱️ 1. Stopwatch

A React-based stopwatch application that measures elapsed time.

#### Features
- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the timer
- ⏱️ Real-time updates
- 📱 Responsive interface

#### Concepts Used
- React Components
- useState Hook
- useEffect Hook
- Event Handling

---

### 🔢 2. Counter App

A simple counter application demonstrating React state management.

#### Features
- ➕ Increment Counter
- ➖ Decrement Counter
- 🔄 Reset Counter
- 🚫 Prevent negative values
- 📱 Responsive UI

#### Concepts Used
- React Components
- useState Hook
- Event Handling
- State Management

---

### ✅ 3. Todo List

A task management application built with React.

#### Features
- ➕ Add Tasks
- ❌ Delete Tasks
- ✔️ Mark Tasks as Completed
- 📋 Display Task List
- 📱 Responsive Design

#### Concepts Used

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/Monish-576/24BCS11152_S.V.R.Monish_FSD-2.git
```

### Navigate to the Repository

```bash
cd 24BCS11152_S.V.R.Monish_FSD-2
```

### Run Any Project

Example for the Stopwatch project:

```bash
cd stopwatch
npm install
npm run dev
```

Example for the Counter project:

```bash
cd counter
npm install
npm run dev
```

Example for the Todo List project:

```bash
cd todo-list
npm install
npm run dev
```
